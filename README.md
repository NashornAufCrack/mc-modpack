# Mod-Katalog 26.3

Vanilla-Visual- und Vanilla-Plus-Modpacks für Minecraft 26.3 (Fabric), mit Pack-Builder und .mrpack-Export.

- Fernsicht: Voxy · Shader: Photon · Spieler-Animation: Punchy
- Feste Versionen: Sodium 0.9.2, Iris 1.11.7, Voxy 0.2.20-beta, Photon v1.4 (nur gemeinsam aktualisieren)
- Import in Prism Launcher: Instanz hinzufügen → Importieren → .mrpack wählen

Die Seite ist eine einzelne statische Datei (`index.html`) und läuft auf GitHub Pages.
